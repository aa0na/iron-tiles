# Iron-Tiles
a simple collection of tiles, icons, and tokens for vtt resources.

## Foundry VTT

### Module
- use jason to install
- or download and unzip
  
### Configuration
- hex columns odd
- measurement .5 units
  - optional
  - allows more freedom in combo tile placement (overlapping)

## Owlbear Rodeo

### Install
- download zip file
- unzip and drag into owlbear rodeo
- files have sizes for flat top hex

### Configuration
- flat top hexes
- no other default changes
- allows combo tile placement (overlapping)
- does not algin with other grids
